# Rascunhos

Artigos escritos e revisados que ficaram fora do site na curadoria de 27/09/2026. Engenharia & IA e Negócios passaram a ter poucos textos de referência, informativos e sem relato pessoal. Estes eram crônica de lançamento (envelhecem rápido) ou repetiam um tema já coberto.

Para publicar um deles: mover de volta para `src/content/insights/`, remover os marcadores `[CONFIRMAR: …]` (a regra agora é texto informativo, sem relato) e rodar `pnpm build`.
