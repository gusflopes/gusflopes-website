## MCP: resumo para artigos

**O que é**: protocolo aberto (JSON-RPC) para conectar aplicações de IA a ferramentas e dados. Criado por David Soria Parra e Justin Spahr-Summers, da Anthropic.

**Versões da especificação** (o identificador é a data da última mudança incompatível: https://modelcontextprotocol.io/specification/versioning)

| Versão | O que trouxe | Fonte |
|---|---|---|
| 2024-11-05 | Primeira versão: tools, resources e prompts; transportes stdio e HTTP+SSE | [P] spec |
| 2025-03-26 | **Streamable HTTP** substitui HTTP+SSE; **autorização com OAuth 2.1**; tool annotations | [S] https://qubittool.com/blog/mcp-2025-spec-oauth-remote-agent-skills |
| 2025-06-18 | **Elicitation**; saída estruturada (`structuredContent`); servidor MCP como OAuth Resource Server (RFC 9728) e Resource Indicators (RFC 8707); PKCE obrigatório | [S] https://blogs.cisco.com/developer/whats-new-in-mcp-elicitation-structured-content-and-oauth-enhancements |
| 2025-11-25 | Tasks (experimental); OAuth **Client ID Metadata Documents**; framework de extensões; auth máquina a máquina; elicitation por URL; sampling com tools | [P] https://blog.modelcontextprotocol.io/posts/2025-11-25-first-mcp-anniversary/ |
| **2026-07-28** (atual) | **Stateless**; `server/discover`; `_meta` com a versão em cada requisição; header `MCP-Protocol-Version`; MCP Apps e Tasks como extensões oficiais; Roots, Sampling e Logging deprecados (mínimo de 12 meses até a remoção) | [P] versioning + RC de 21/05/2026 |
