A Microsoft lançou no Ignite, em 17/11/2026, dois modelos próprios de código: o MAI-Code-2, para trabalho pesado de agente, e o MAI-Code-2-Flash, para o volume do dia a dia. Os dois estão disponíveis no GitHub Copilot; o Flash também está em prévia limitada no Microsoft Foundry.

Segundo a Microsoft, o MAI-Code-2 chega a 96% do desempenho do Claude Opus 5.5 por 5% do preço, na média de quatro benchmarks escolhidos pela empresa (DeepSWE 1.1, Terminal Bench 2.1, SWE-Atlas e FrontierCode v1.1). A página não traz preço absoluto por token.

É a primeira vez que a Microsoft põe modelo de código próprio para competir dentro do Copilot com os modelos dos parceiros. Número de fornecedor sobre o próprio modelo é ponto de partida para teste, não conclusão.
