O GitHub liberou em 18/11/2026, em preview pública para todos os planos do Copilot, oito conectores novos, que são servidores MCP verificados: Box, Buildkite, Calendly, ClickUp, Mixpanel, Supabase, Webflow e Wix.

No Business e no Enterprise, o admin precisa ligar a política de preview e, se a allowlist de MCP for nominal, incluir cada conector.

A escolha entre allowlist com curinga e nominal passa a ser decisão de governança: uma deixa entrar conector novo sem decisão de ninguém, a outra trava o time até o admin agir.
