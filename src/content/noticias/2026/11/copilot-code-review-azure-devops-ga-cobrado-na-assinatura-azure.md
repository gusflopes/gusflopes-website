O GitHub tornou disponível para todos, em 17/11/2026, a revisão de código do Copilot no Azure Repos, o repositório do Azure DevOps. O admin pode criar uma política de branch que pede a revisão automaticamente em todo pull request.

O uso é cobrado em créditos de IA do GitHub na assinatura Azure ligada à organização, com acompanhamento e alerta de gasto pelas ferramentas de custo do Azure. No mesmo dia entrou em prévia o esforço adaptativo, que escolhe entre os níveis Lite, Balanced e Max conforme a complexidade e o risco de cada PR.

Muita empresa brasileira de .NET está no Azure DevOps, não no GitHub. Para ela, a revisão por IA deixa de ser experimento e vira item de orçamento de engenharia, com alguém decidindo o nível de esforço e quem aprova depois da máquina.
