A Microsoft anunciou no Ignite, em 17/11/2026, a disponibilidade geral do Microsoft Copilot SDK 2.0. O harness do Copilot, a camada que orquestra modelo, ferramentas e contexto, passa a rodar num runtime nativo em Rust, e o SDK atende seis linguagens, que o anúncio não lista.

O SDK é o antigo GitHub Copilot SDK, cuja mudança de nome o GitHub anunciou em 28/10/2026; nomes de pacote e documentação podem continuar com o nome antigo durante a transição.

O que roda o Copilot dentro das ferramentas da Microsoft vira peça estável para quem constrói o próprio agente. Faltam, na fonte, a lista de linguagens e qualquer referência de preço.
