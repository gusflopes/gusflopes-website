A Perplexity lançou em 17/11/2026, em disponibilidade geral, o Orchestrator: uma API única para modelos da OpenAI, Anthropic, Google, xAI e modelos abertos, com cobrança unificada e failover entre provedores.

A API é compatível com os formatos Chat Completions, Responses e Anthropic Messages, e a Perplexity diz que não cobra taxa de plataforma sobre os créditos.

A Perplexity entra num mercado que já tem OpenRouter, Hugging Face e Cloudflare. Para o arquiteto, quem decide para qual modelo vai cada chamada vira a dependência real, mais do que o modelo.
